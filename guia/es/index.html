Qué es

Un mentor que copia el método, no a la persona

Cuando le pides a una IA que te explique algo, suele explicar de más, parecer segura sin estarlo, suponer cosas sin avisar y responder en genérico. Este kit arma un mentor que enseña a la manera de alguien que admiras, con prueba para cada paso.

📚 Conocimiento real, organizado

Todo lo que el experto publicó (videos, textos, repositorios, posts) se convierte en una wiki interconectada que la IA consulta sin perderse en el pajar.

🔎 Reglas con prueba

Cada regla de conducta lleva un fragmento copiado del acervo y el lugar exacto de donde salió. Un script rechaza la cita inventada.

▶️ Solo habla después de ejecutar

El mentor sigue un paso a paso fijo, y una compuerta automática no deja terminar el turno si se escribió código y no se ejecutó.

Cómo funciona

Seis capas, cada una con prueba de terminado

Cada fase tiene un comando que responde "¿terminó?" con exit 0 o con el motivo de la reprobación. Nada depende de que la IA diga que acabó.

Acervo en bruto→ Wiki compilada→ Reglas con cita→ Agente + skills→ Compuerta de ejecución→ Ingesta continua
1

Acervo y wiki

raw/ es de solo lectura, con manifiesto y hash de cada ítem. La wiki tiene páginas de fuentes, temas, principios y métodos, además de index, hot y log.

2

Reglas

activa exige 2 fuentes distintas; banco espera la 2.ª; inferencia se le avisa al usuario. La comparación ignora mayúsculas, acentos y puntuación.

3

El loop del mentor

Listo → Versión mínima → Predicción → Salida real → Versión rota → Informe con la regla que guio cada paso.

Los scripts usan solo la biblioteca estándar de Python. Nada de API de pago.

Python 3.10+ y git

Para el generador, los recolectores y los validadores.

Claude Code

Guía de uso · paso a paso

De cero a tu primer mentor

Comandos reales del kit. Cambia prof-redes por el nombre corto de tu mentor.

1

Descarga el kit y ve el ejemplo funcionando

El ejemplo es una experta ficticia con 3 fuentes y 7 reglas, que pasa todos los validadores.

git clone https://github.com/inematds/mentor-especialista.git
cd mentor-especialista
python3 exemplo/tools/stats.py --raiz exemplo
python3 exemplo/tools/validar_citacoes.py --raiz exemplo
2

Crea tu mentor

Genera la carpeta con el acervo, la wiki, las reglas, los scripts, el agente, las 6 skills y la compuerta de ejecución.

python3 novo-mentor.py prof-redes \
  --nome "Nombre del experto" \
  --dominio "enseñar redes neuronales construyendo desde cero" \
  --destino ~/mentores
3

Define el alcance y ajusta a tu entorno

En ESCOPO.md van las fuentes. En mentor.config.json van las metas de recolección, los idiomas de subtítulos y tu transcriptor (ver docs/ADAPTAR.md (en portugués)).

cd ~/mentores/mentor-prof-redes
# en mentor.config.json, por ejemplo:
"transcrever_cmd": "seu-transcritor --url {url} --out {saida}"
4

Recolecta el acervo

En Claude Code, dentro de la carpeta del mentor. Un subagente por fuente, en paralelo. Lo que falle va a raw/RELATORIO-FALHAS.md.

/prof-redes-coletar
# listo cuando:
python3 tools/stats.py   # → exit 0 (metas cumplidas, raw intacto)
5

Compila la wiki y extrae las reglas

La wiki enlaza fuentes, temas, principios y métodos en ambos sentidos. Las reglas salen con un fragmento copiado del acervo.

/prof-redes-compilar
python3 tools/validar_links.py     # → 0 enlaces rotos
/prof-redes-regras
python3 tools/validar_citacoes.py  # → 0 faltantes
6

Aprende y revisa con el mentor

ensina construye contigo y verifica la respuesta por fuera. revisa predice dónde se rompe, lo reproduce y prueba la versión depurada lado a lado.

/prof-redes-ensina enséñame a hacer un tokenizador BPE desde cero
/prof-redes-revisa scripts/coleta.py
python3 tools/validar_resposta.py testes/respostas/<arquivo>.md
7

Haz que el mentor aprenda algo nuevo

Un enlace nuevo se convierte en página de fuente, actualiza las páginas afectadas y puede promover una regla de banco a activa.

/prof-redes-ingere https://exemplo.com/post-novo
python3 tools/stats.py && python3 tools/validar_links.py && python3 tools/validar_citacoes.py
8

Ejecuta las 3 pruebas de aceptación

Construir y enseñar; revisar un script que "funciona" pero se rompe sin UTF-8; ingerir una fuente nueva. Los resultados van en testes/aceitacao/RESULTADOS.md.

PYTHONIOENCODING=cp1252 python3 testes/aceitacao/script_emoji.py
# → UnicodeEncodeError: el mentor debe preverlo antes de ejecutar
