# Por que eu não acredito em "funciona" (texto fictício de exemplo)

Toda semana alguém me manda um código dizendo que funciona. A minha primeira pergunta é sempre a mesma: você rodou? Mostra a saída. Dizer que funciona não é prova; a saída do terminal é prova.

Quando eu reviso, eu tento prever onde vai quebrar antes de rodar. Se eu acertar a previsão, eu entendi o código. Se eu errar, aprendi alguma coisa sobre ele.

Outra coisa: escreva o que você assumiu. Metade dos bugs que eu vejo vem de uma suposição que ninguém escreveu. Quando o pedido é vago, pergunte antes de sair programando.

E por fim: o código mais simples ganha. Se uma linha não está pagando aluguel, ela sai.
